<h1>Setup</h1>
<italic>Python 3 must be installed</italic>
<br>
<italic>VSCode must be installed with the python extension (by Microsoft) also installed</italic>

<h1>For macOS </h1>
<code>python3 -m venv venv</code><br>
<code>source venv/bin/activate</code><br>
<code>pip install -r requirements.txt</code><br>

<h1>For Windows ⊞ 🗑 (using PowerShell)</h1>
<code>python -m venv venv</code><br>
<code>Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process</code><br>
<code>.\venv\Scripts\Activate.ps1</code><br>
<code>pip install -r requirements.txt</code>
